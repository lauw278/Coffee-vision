# CoffeeVision — Coffee Ripeness & Quality Classification

An experimental computer vision project exploring image-based coffee cherry ripeness classification and coffee bean quality assessment.

## Project Overview

CoffeeVision explores the application of computer vision and machine learning to coffee quality assessment through image analysis.

The project focuses on two areas:

1. **Coffee Cherry Ripeness Classification** — Exploring four ripeness categories: overripe, ripe, semi-ripe, and unripe.
2. **Coffee Bean Quality Assessment** — Exploring visual quality categories, including Specialty, Good Bean, Slight Defect, Defect, and Severe Defect.

## Project Objectives

- Explore computer vision techniques for coffee image classification.
- Understand image preprocessing and data augmentation.
- Experiment with convolutional neural network (CNN) architectures.
- Investigate image classification approaches for coffee quality assessment.
- Evaluate classification performance using appropriate metrics.
- Develop a web interface for image-based classification demonstrations.

## Current Project Status

The project is currently in the experimental development stage.

The repository includes a browser-based interface and an experimental machine-learning notebook. Model training, classification performance, and prediction reliability have not yet been independently validated.

## Future Development

- Implement and train a classification model.

- Integrate a trained model with the web interface.

The long-term goal is to explore how computer vision can assist in coffee quality assessment and contribute to more consistent, image-based evaluation workflows.
